Student Planner — Claude Code Instructions

Project Overview

Student Planner is a web application that helps students organize academic tasks, manage deadlines, and track study progress.

Before Starting Work
	•	Read README.md.
	•	Read AGENTS.md.
	•	Read _docs/plan.md.
	•	Read _docs/process.md.
	•	Read the relevant GitHub Issue.

Development Rules
	•	Work on one issue at a time.
	•	Follow the issue requirements and acceptance criteria.
	•	Keep changes small and focused.
	•	Do not introduce unrelated features.
	•	Ask for clarification when requirements are unclear.

Code Quality
	•	Write clear and maintainable code.
	•	Validate user inputs.
	•	Add or update relevant tests.
	•	Run tests when possible.
	•	Report test results honestly.

Documentation
	•	Update documentation when project requirements change.
	•	Keep setup instructions accurate.
	•	Explain important implementation decisions.

Completion Report

After completing a task, summarize:
	1.	What changed.
	2.	Which files were created or modified.
	3.	Which tests were run.
	4.	Whether the tests passed.
	5.	Any remaining issues.
