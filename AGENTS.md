Student Planner — Agent Instructions

1. Project Purpose

Build a simple Student Planner web application that helps students manage academic tasks and deadlines.

2. Working Rules
	•	Read the project documentation before making changes.
	•	Follow the requirements in _docs/plan.md.
	•	Work on one task at a time.
	•	Keep changes small and easy to review.
	•	Do not add features that are outside the current project scope without approval.

3. Code Quality
	•	Use clear and understandable code.
	•	Use meaningful file and variable names.
	•	Validate user inputs.
	•	Handle errors appropriately.
	•	Test functionality after making changes.

4. Documentation
	•	Update documentation when project requirements change.
	•	Keep the README accurate.
	•	Explain important decisions clearly.

5. Development Process
	•	Review the relevant GitHub Issue before starting work.
	•	Implement only the requested changes.
	•	Run relevant tests.
	•	Summarize what changed and what was tested.
