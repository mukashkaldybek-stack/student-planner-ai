Student Planner

A simple web application that helps students organize academic tasks, manage deadlines, and track their study progress.

Problem

Students often struggle to organize assignments and remember important deadlines.

Goals
	•	Organize academic tasks.
	•	Set and track deadlines.
	•	Mark tasks as completed.
	•	Make studying easier to manage.

Planned Features
	•	Create tasks.
	•	View a list of tasks.
	•	Edit and delete tasks.
	•	Set deadlines.
	•	Track task completion.

Future Improvements
	•	AI-powered study schedule suggestions.
	•	Smart task prioritization.
	•	Personalized study recommendations.

Technology Stack
	•	Python
	•	Flask
	•	SQLite
	•	HTML and CSS
	•	pytest

Requirements
	•	Python 3.11 or a compatible Python version.
	•	pip
