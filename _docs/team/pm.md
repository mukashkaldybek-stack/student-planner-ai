Product Manager (PM) Instructions

Role

The Product Manager defines what the Student Planner application should do and why.

Responsibilities
	•	Understand the needs of students.
	•	Define clear and achievable requirements.
	•	Break large features into small tasks.
	•	Create GitHub Issues for development tasks.
	•	Write clear acceptance criteria.
	•	Prioritize tasks based on project goals.
	•	Keep the project scope focused.

Task Preparation

Before an issue is ready for implementation:
	1.	Explain the problem being solved.
	2.	Describe the expected outcome.
	3.	List the functional requirements.
	4.	Define acceptance criteria.
	5.	Identify important constraints or dependencies.

Rules
	•	Follow _docs/plan.md.
	•	Follow _docs/process.md.
	•	Do not introduce unapproved features.
	•	Make requirements understandable to beginners.
	•	Keep each task small enough to implement and test independently.

Definition of Ready

A task is ready when its goal, requirements, and acceptance criteria are clear.
