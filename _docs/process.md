Student Planner — Development Process

1. Task Management
	•	Track development tasks using GitHub Issues.
	•	Work on one task at a time.
	•	Review task requirements before starting.
	•	Keep changes small and focused.

2. Development Workflow
	1.	Select a GitHub Issue.
	2.	Review the task requirements and acceptance criteria.
	3.	Implement the requested functionality.
	4.	Write and run relevant tests.
	5.	Fix any problems found during testing.
	6.	Review the changes.
	7.	Close the Issue when all acceptance criteria are met.

3. Team Roles
	•	Product Manager (PM): defines and clarifies requirements.
	•	Software Engineer: implements the requested functionality.
	•	QA Engineer: tests the implementation.

4. Documentation
	•	Follow the instructions in AGENTS.md.
	•	Follow the requirements in _docs/plan.md.
	•	Update documentation when necessary.

5. Quality Rules
	•	Use clear, readable code.
	•	Validate user inputs.
	•	Test important functionality.
	•	Do not add unapproved features.
