# Student Planner — Project Brainstorm

## 1. Project Idea
Student Planner is a web application that helps students organize academic tasks, manage deadlines, and track their study progress.

## 2. Problem
Students often struggle to manage assignments, remember deadlines, and organize their study schedules.

## 3. Target Users
- University students
- College students
- Students who want to organize their academic work

## 4. Core Features
- Create and manage academic tasks
- Set deadlines for assignments
- Track task completion status
- View upcoming deadlines
- Organize study activities

## 5. Future AI Features
- Suggest a study schedule
- Prioritize tasks based on deadlines
- Provide personalized study recommendations

## 6. Initial Scope
The first version will focus on basic task management, deadlines, and task status tracking.

Advanced AI features may be considered in later versions.
